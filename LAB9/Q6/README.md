6. **[Reorganise String with K-Distance Apart]** Given a string $S$ and an integer $K$, rearrange $S$ such that the same characters are at least distance $K$ apart. If impossible, return an empty string. By choosing the proper input representation, write a program in C to validate your algorithm and derive the complexity analysis of your algorithm.
