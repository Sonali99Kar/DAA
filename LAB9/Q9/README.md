9. **[Hu-Tucker Greedy Simulation] $\ast$** Given an ordered sequence of weights $w_1, w_2, \dots, w_n$, construct an optimal alphabetic binary search tree or merge pattern that maintains the strict in-order sequence of indices while minimizing $\sum w_i \cdot \text{depth}(i)$. By choosing the proper input representation, write a program in C to validate your algorithm and derive the complexity analysis of your algorithm.
